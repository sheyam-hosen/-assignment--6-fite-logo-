# FitLog – Workout & Fitness Tracker

FitLog is a modern and responsive fitness tracking web application built with Next.js. It helps users explore workouts, view exercise details, save favorite workouts, and manage their daily fitness plans in one place.

## 🛠️ Technologies Used

- **Next.js** – React framework
- **React** – UI development
- **TypeScript** – Type-safe development
- **Tailwind CSS** – Responsive styling
- **REST API** – Workout data fetching

## ✨ Key Features

1. **Workout Library** – Browse and explore available workouts.
2. **Workout Details** – View detailed information about each workout.
3. **Save Workouts** – Save favorite workouts for later.
4. **Daily Workout Plan** – Add and manage workouts in your daily plan.
5. **Fitness Tracking** – Track workout duration and estimated calories burned.
